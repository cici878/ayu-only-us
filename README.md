# Only Us · 予你晴空（第一版原型）
这是一个可点击的 PWA 前端原型。当前包含桌面、聊天/手记/音乐/日历/朋友圈/记忆中心/API中心/应用商店/设置等界面入口。

## 上传到 GitHub
1. 下载并解压 `only-us-v1.zip`。
2. 进入你的 GitHub 仓库，选择 Add file → Upload files。
3. 上传解压后的所有文件和 `assets` 文件夹里的内容（保持目录结构）。
4. Commit changes。
5. 仓库 Settings → Pages → Deploy from a branch → main / root → Save。

## 注意
当前是界面与本地交互原型，不包含真实 AI、云端同步、音乐播放、推送通知或真实 API 密钥保存。不要将真实 API Key 放进前端文件。正式功能需要后端服务与权限设计。
